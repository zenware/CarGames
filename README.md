# CarGames

Offline-first, silent, big-button car games built for a **Passenger** operating the phone and a **Driver** playing eyes-free.

**Play live:** https://zenware.github.io/CarGames/  
*(On iPhone Safari: Share → **Add to Home Screen** for full-screen + offline caching.)*

## Current Game: The Song Game
- **Human Clue + Bluff Check (`Prove It!`):** One player picks a word, the other proves a song with that word in the lyrics (title + artist, or singing a lyric)—or challenges the clue-giver to prove it.
- **App Deal:** Offline Easy / Medium / Hard word decks (no repeats per trip).
- **Classic & Rapid modes:** Classic guides each word (human clue or dealt, optional verify/bluff check, records invisible solve-time metadata); Rapid is a giant points-only scoreboard for fast verbal play.
- **Optional LRCLIB Lyric Check:** Verifies whether a song actually contains the word in its lyrics (and catches title-only traps), with an automatic **offline queue** for highway dead zones.
