# CarGames

Offline-first, silent, big-button car games built for a **Passenger** operating the phone and a **Driver** playing eyes-free.

**Play live:** https://zenware.github.io/CarGames/  
*(On iPhone Safari: Share → **Add to Home Screen** for full-screen + offline caching.)*

## Games
- **🎵 The Song Game:** Prove a song with the target word in its lyrics (Classic with human clues/dealt words/Bluff Check/LRCLIB lyric verify + invisible solve-time metadata, or Rapid points-only mode).
- **🔤 Prefix Reveal:** Blind left-to-right letter guessing (word hidden from everyone, including the Passenger MC) so Driver and Passenger share equal working-memory load.
- **🗂️ Categories:** Volley answers until someone stalls—supports **Points** (everyone else +1) and **Elimination** (last one standing) plus an optional random starting letter.
